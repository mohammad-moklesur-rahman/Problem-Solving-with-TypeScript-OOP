Access Modifiers TypeScript-এ Class-এর Property এবং Method-এর Access নিয়ন্ত্রণ করে।
- public: যেকোনো জায়গা থেকে Access করা যায়।
- private: শুধু নিজের Class থেকে Access করা যায়।
- protected: Parent এবং Child Class থেকে Access করা যায়।
- readonly: Initialize করার পর নতুন Value Assign করা যায় না।
এগুলো OOP-এর Encapsulation বাস্তবায়নে সাহায্য করে।
