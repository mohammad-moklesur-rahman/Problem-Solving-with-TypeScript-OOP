Type Alias এবং Interface দুটোই TypeScript-এ Type নির্ধারণ করার জন্য ব্যবহার করা হয়। তবে এদের মধ্যে কিছু পার্থক্য রয়েছে।

Interface মূলত Object-এর Structure নির্ধারণ করতে ব্যবহৃত হয় এবং এটি Declaration Merging ও extends সাপোর্ট করে।

অন্যদিকে, Type Alias আরও Flexible। কারণ এটি Primitive, Union, Intersection, Tuple এবং বিভিন্ন Complex Type তৈরি করতে পারে।
